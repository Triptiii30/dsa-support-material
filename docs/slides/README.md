# Course Presentation & Reference Slides

This directory archives the course lecture slides and reference presentations associated with the Data Structures & Algorithms Project-Based Learning (DSA PBL) curriculum:

- **[`Unit-1_Trees.pptx`](./Unit-1_Trees.pptx)**: Unit 1 — Trees, Binary Search Trees, and AVL Self-Balancing Trees.
- **[`Unit-2_DSA.pptx`](./Unit-2_DSA.pptx)**: Unit 2 — Graph Theory, Traversals (BFS, DFS), Minimum Spanning Trees (Prim, Kruskal), and Shortest Paths (Dijkstra, Bellman-Ford, Floyd-Warshall).
- **[`Unit-3_DSA.pptx`](./Unit-3_DSA.pptx)**: Unit 3 — Dynamic Programming, 0/1 Knapsack, LCS, Matrix Chain Multiplication, and Resource Allocation.
